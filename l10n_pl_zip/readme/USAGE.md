1. As an administrator, open **Contacts → Configuration → Localization → Cities** and search
   for a postal code: the Polish localities of that postal code are listed with their voivodeship.

   ![Cities list filtered on the postal code 04-410: the localities Dzbenin, Warszawa, all of the state mazowieckie (PL)](static/description/en/01_lista_localitati_cap.png)

2. Open a Polish contact and type the postal code in the address: the city and the region are
   filled in.

   ![Contact in Poland: the postal code 00-002 fills in the city Warszawa and the state mazowieckie (PL)](static/description/en/02_partener_cap_unic.png)

3. When the postal code is shared by several localities, only the region is filled in; choose the
   city from the list (type the postal code or the name in the city field).

   ![Contact in Poland: the postal code 04-410 fills in the state mazowieckie (PL); the city field lists the localities of 04-410](static/description/en/03_partener_cap_comun.png)

4. To complete existing or imported contacts, select them in the list and run
   *Actions → Poland: set city from ZIP*.

   ![Contacts list with Polish contacts selected and the Actions menu open on Poland: set city from ZIP](static/description/en/04_actiune_contacte_existente.png)

   ![Contact Customer Dzbenin after the action: ZIP 04-410, city Dzbenin (04-410) and state mazowieckie (PL)](static/description/en/05_contact_dupa_actiune.png)
